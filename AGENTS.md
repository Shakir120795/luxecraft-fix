# AI Agent Entry Point

This repository is a model-agnostic AI development project.

Before changing code:

1. Read `.ai/PROJECT_SPEC.md`.
2. Read `.ai/ARCHITECTURE.md`.
3. Read `.ai/DEVELOPMENT_RULES.md`.
4. Read `.ai/DECISIONS.md`.
5. Read `.ai/CURRENT_STATE.md`.
6. Read `.ai/TASK_QUEUE.md`.
7. Inspect the existing implementation.

Do not restart the project from scratch.

Use the canonical specification as the source of truth.

If a requirement conflicts with a locked decision, stop and ask.

After implementation:

- Run relevant checks.
- Update current state.
- Update task queue.
- Report exactly what changed and what was verified.
